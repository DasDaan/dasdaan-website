# Portfolio Site

Welcome to the (sort of) Portfolio Site project!

## 🚀 Getting Started

Follow these instructions to get the project up and running on your local machine.

### Installation

1.  **Clone the repository** (if you haven't already):

    ```bash
    git clone <repository-url>
    cd portfolio-site
    ```

2.  **Install dependencies**:
    This project uses `npm` to manage dependencies. Run the following command in the project root:
    ```bash
    npm install
    ```

### 💻 Running the Application

To start the development server and view the site locally:
`npm run dev`


Once the server is running, you'll see a local URL (usually `http://localhost:5173`) in your terminal. Open that URL in your browser to see the site.

### 🏗️ Building for Production

When you're ready to deploy, you can build the project for production. This creates a highly optimized version of your app in the `dist` directory.
`npm run build`

To preview the production build locally:
`npm run preview`
